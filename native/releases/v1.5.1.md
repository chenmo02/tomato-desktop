番茄桌面 1.5.1：在 v1.5 基础上补齐「微信式」托盘后台驻留、托盘右键菜单美化与进程级硬退出；窗口调整仍集中在设置页，新增窗口置顶开关。

本版本是已发布的 `v1.5` 的后续修正版。线上 `v1.5` 只包含菜单瘦身与设置页窗口调整，托盘相关功能并未包含在该安装包中。下面同时列出 1.5 系列全部改动，便于从 1.4 及更早版本直接升级的用户了解完整变化。

## 1.5.1 新增与修正

- **点 × 不再退出进程**：窗口隐藏到通知区，托盘图标常驻，左键 / 双击或热键唤起，右键可打开面板、打开设置或退出并结束进程；首次收起会提示一次。系统注销 / 关机自动放行，托盘图标在退出时释放。
- **「设置 → 行为」新增「隐藏到托盘」按钮**；「关闭时结束进程」默认关闭并改用新注册表键 `CloseEndsProcessV2`，旧版本残留的旧值不再继承。真退出入口保留在托盘右键菜单、设置页「关于」与「更多」菜单。
- **托盘右键菜单美化**：弃用 WinForms 系统默认的直角白底 + 纯蓝选中块，改为复用主界面 WinUI 样式的 WPF 圆角卡片（投影、中性描边、悬停高亮）；新增番茄图标品牌头与版本 / 后台状态、三行线性图标、热键提示，退出项用系统红区分。番茄图标直接落在卡片上，不套彩色底块。配色全部走 `DynamicResource`，浅色 / 深色与两套皮肤自动跟随；按光标所在显示器 DPI 定位，窗口隐藏在后台时仍可弹出。
- **点击菜单外立即收起**：主窗口隐藏到托盘后，WPF Popup 的 `StaysOpen=false` 收不到失焦通知，所以菜单打开期间按需安装全局低级鼠标钩子（仅监听按键按下、按 Popup HWND 矩形判定内外，菜单关闭即卸载），点击桌面、其它窗口或托盘图标都会收起菜单；菜单内部点击不误关，Esc 仍由 Popup 处理。
- **「退出并结束进程」改为真正的进程级硬退出**：此前只调 `Application.Shutdown()`，托盘常驻状态下会出现「窗口已隐藏、进程仍在」的僵尸实例，既让托盘退出看起来没生效，也会继续锁住程序集导致 VS 报 `MSB3021 / MSB3027`。现在由 `AppExit.cs` 统一收口：先收起菜单并卸载鼠标钩子、注销全局热键、停掉自动收纳计时器、释放托盘图标、注销 IPC 等待与单实例互斥体、删除 `instance.pid`，再直接 `Environment.Exit(0)`。托盘右键、设置页「关于」、「更多」菜单、关闭偏好、安装 / 卸载的停止信号、系统注销与单实例副本全部走这条路径；退出后任务管理器不再有 `DesktopNook.exe`。
- **自检增强**：核心检查 33/33、尺寸自检 60/60、UI 自检 84/84、在线更新专项 7/7（模拟 feed）；新增托盘退出项的进程级退出与资源清理断言。`scripts/Verify-StartupExit.ps1` 另在真实进程上验证 8 项：自启最小化、单实例副本立即退出、× 隐藏到托盘、托盘唤起、关闭偏好终止进程、「更多」退出终止进程、`--verify-tray-exit` 隐藏态托盘退出项终止进程、收纳数据不变。Debug / Release 各 8/8 通过，退出后验证进程残留为 0；脚本同时修正为 UTF-8 BOM + CRLF，避免 Windows PowerShell 5.1 按 ANSI 误读中文注释吞掉换行。设置页与托盘菜单的浅色 / 深色渲染均已核对，无裁切与重叠。

## 1.5 已有功能

- 移除「更多 → 文件管理」与「更多 → 窗口大小」两个子菜单；打开数据目录的能力仍保留在「更多」菜单与设置页。
- 「设置 → 窗口调整」分组：窗口大小（80% / 100% / 125% / 150% 四档预设或自由调整）、锁定宽高比、恢复默认大小、贴回任务栏，全部由原菜单迁入，尺寸与位置偏好不变。
- 「窗口置顶」开关默认开启（沿用原有常驻行为）；关闭后面板按普通窗口层级显示。偏好写入 `AppSettings`，随配置包导入导出。

## 升级方式

从 `v1.5` 或 `v1.4.x` 升级：程序启动后会在后台检查并提示 `v1.5.1`，也可点「更多 → 检查在线更新」手动下载升级；直接下载 `DesktopNook-Setup.exe` 覆盖安装同样有效。从 1.2 及更早版本升级：这些版本未启用在线检查，请下载安装包覆盖安装一次，或使用「更多 → 从本地文件更新…」选择安装包。分类、收纳内容与设置保留在原位。

Windows x64，程序内含运行时，安装到 %LOCALAPPDATA%\DesktopNook，无需管理员权限。
