统一更新窗口，并启用在线更新。

- 更新流程收敛到一个 480 px 窗口：检查中、发现新版本、下载中、校验与准备、等待重启、已是最新、失败等状态在同一窗口切换，不再跳转多个尺寸的弹窗。
- 下载页显示文件名、百分比、已下载 / 总量与「下载 → 校验 → 准备 → 重启」四段阶段，可随时取消；失败时可重试、关闭或改用本地文件。
- 确认页只显示「当前版本 → 目标版本」与数据安全声明；深浅主题、系统强调色与两套皮肤跟随主面板。
- 在线更新已启用：启动后后台检查（只提示、不自动安装），也可从「更多 → 检查在线更新」手动检查；下载后核对来源、大小、SHA-256、产品名与版本，在原位置更新并重启。
- 保留「更多 → 从本地文件更新…」；分类、收纳内容与设置均保留。

从 1.2 及更早版本升级：这些版本未启用在线检查，请下载 `DesktopNook-Setup.exe` 覆盖安装一次，或使用「更多 → 从本地文件更新…」选择安装包。完成 1.3 安装后，后续版本即可在软件内在线更新。

Windows x64，程序内含运行时，安装到 %LOCALAPPDATA%\DesktopNook，无需管理员权限。
