番茄桌面 1.5.2：按用户反馈重做安装体验——安装位置可以自选、安装速度明显提升；同时新增 Esc 一键关闭页面。全局热键保持原来的 `Ctrl + Alt + T` 不变。

## 新增与修正

- **按 Esc 关闭页面**：在面板任意页面按 Esc 即关闭整个面板，与点标题栏 × 走完全相同的路径——默认隐藏到托盘后台运行，托盘图标常驻；若在「设置 → 行为」开启「关闭时结束进程」，则直接退出进程。在设置页或图标库按 Esc 会先复位回图标页再关闭，下次唤起不会停留在旧页面。弹出菜单打开时由菜单自身先消费 Esc，避免一次按键既关菜单又关窗口；拖拽中与自检模式保留原有保护。设置页「行为」分组的说明文案已同步。
- **全局热键维持 `Ctrl + Alt + T`**：曾试改为 `Ctrl + 空格`，但该组合常被中文输入法用作中 / 英文切换，容易被截获，因此本版本恢复原来的组合。设置页、托盘菜单与状态提示保持一致。
- **安装位置可自选**：安装向导新增「程序安装位置」页，默认仍是当前用户的 `AppData\Local\DesktopNook`，可改成任意当前用户可写的目录；选择需要管理员权限的系统目录时会被自动拦住。覆盖升级自动沿用上次登记的安装位置，注册表 `InstallLocation` 记录实际路径。换目录安装时只清理旧位置的程序文件与卸载器，旧目录里还有数据或其它文件时自动跳过，不会误删。
- **收纳数据位置不变**：分类、收纳内容、设置与备份始终保存在 `%LOCALAPPDATA%\DesktopNook`，与程序文件装在哪里无关；覆盖升级不改动数据。
- **安装提速**：压缩方式由 `/SOLID lzma` 改为 `/FINAL zlib`；覆盖升级时直接用旧 EXE 执行 `--maintenance=stop`，不再把 175 MB 载荷解压两次、启动两次进程；「固定到快速访问」的 Shell 等待上限由 8 秒缩短到 2.5 秒，超时写 `nav-pin-report.json`，由应用首次启动时在独立 STA 后台线程补做，不阻塞安装。同一载荷实测：静默首次安装约 5.35 秒 → 约 1.47 秒，同目录升级约 1.87 秒，makensis 出包约 58 秒 → 约 17 秒。
- **取舍说明**：zlib 压缩率低于 LZMA，安装包体积由约 51 MB 增至约 71 MB，下载会稍慢，换来的是安装与升级明显更快。若更看重下载体积，可把压缩器改回 `/SOLID lzma`，其余提速措施不受影响。

## 升级方式

从 `v1.5.1` 或更早的 1.3 / 1.4 / 1.5 版本升级：程序启动后会在后台检查并提示 `v1.5.2`，也可点「更多 → 检查在线更新」手动下载升级；直接下载 `DesktopNook-Setup.exe` 覆盖安装同样有效，安装向导会沿用原先的安装位置。从 1.2 及更早版本升级：这些版本未启用在线检查，请下载安装包覆盖安装一次，或使用「更多 → 从本地文件更新…」选择安装包。分类、收纳内容与设置保留在原位。

Windows x64，程序内含运行时，安装无需管理员权限。
