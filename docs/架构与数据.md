## 数据保存

数据根目录固定为 `%LOCALAPPDATA%\DesktopNook`（由 `App.xaml.cs` 的 `SpecialFolder.LocalApplicationData` 决定，与 EXE 所在位置无关；安装向导允许自选程序安装目录，默认恰好与数据目录相同），包含：

- `state.json` / `state.json.bak`：分类与收纳索引及备份。
- `migration.json`：进行中的操作日志，用于中断恢复。
- `vault/<id>/`：逐项恢复清单、快捷方式副本或同卷托管内容。
- `updates/`：下载、更新计划、元数据快照及更新结果。
- `instance.pid`：当前实例定位信息。
- `nav-pin-report.json`：导航入口诊断（Shell 动词、快速访问项、「此电脑」枚举、命名空间注册状态），由 `--maintenance=shortcut` / `nav-pin` / `nav-diagnose` 写出。
- `HKCU\Software\Classes\CLSID\{73EEDBFB-…}` 与 `HKCU\…\Explorer\MyComputer\NameSpace\{73EEDBFB-…}`：把展示目录注册成左侧导航窗格项，指定 `DefaultIcon`、`TargetFolderPath` 与 `System.IsPinnedToNameSpaceTree`；当前用户级，卸载时整键删除。
- `番茄桌面/`：资源管理器导航入口的展示目录，只含指向托管文件的 `.lnk`、隐藏的 `desktop.ini` 与 System 属性，不存放用户原件；卸载时清理。
- `AppIcon.ico`：从程序资源提取的软件图标，供 `desktop.ini` 的 `IconResource` 引用；放在数据目录而非展示目录，避免点开入口时看到图标文件；卸载时清理。
- `DesktopNook.exe` 与 `卸载番茄桌面.exe`：程序本体与卸载器；覆盖升级只替换这两个文件，其余数据项不受影响。卸载恢复成功后，数据根目录本身保留，由用户手动清理。

普通文件和文件夹优先同卷原子移动；与数据目录不同卷时，内容保存在原桌面同卷的隐藏 `.DesktopNookVault` 中，恢复信息仍位于数据目录。只备份 JSON 或默认数据目录不能覆盖所有跨卷实际内容。

收纳普通文件后的编辑会随移回保留。同名目标不覆盖；目录联接、符号链接及未落地的云占位内容不按普通实目录处理。

快捷方式通过内容校验和逐项清单保留恢复依据。操作中断时，根据日志、托管内容及源/目标实际状态恢复。恢复副本及更新备份均保存在本机，不构成云备份。

## 偏好与系统入口

窗口尺寸和关闭偏好位于 `HKCU\Software\DesktopNook\Settings`；自启使用当前用户的 Windows Run 项。窗口比例只调整窗口，内容维持默认尺度并自动计算列数。主题、强调色、皮肤、提示条、「失焦时自动收起」与「显示系统项目」等应用级偏好以单个 `AppSettings` JSON 存在同一注册表项下，新增字段随配置包导出/导入整体搬运；脏值由 `SkinService.Normalize` 回落到原生皮肤。`AutoHideOnDeactivate` 默认 false，`MainWindow.OnDeactivated` 直接返回，面板只能通过 × / Esc / 热键 / 任务栏按钮手动关闭。

回收站收纳保存并调整当前用户 Explorer 的桌面图标可见性设置，移回时还原，不移动回收站内容。

## 后台资源生命周期

进程常驻的最小集合是两个 IPC 事件等待（单实例激活与维护退出）、全局热键的 `WM_HOTKEY` 钩子、常驻通知区图标（`TrayService`），以及主窗口的视觉树。退出时两个 `RegisteredWaitHandle` 会显式注销、单实例互斥体释放并删除 `instance.pid`，托盘图标在 `MainWindow.Quit()` 与主窗口 `Closed` 事件里都会释放（幂等）。托盘右键菜单打开期间会额外安装一个 `WH_MOUSE_LL` 低级鼠标钩子（因为隐藏窗口下的 Popup 收不到失焦通知），菜单一关闭就卸载，不常驻；回调只判断按键按下与 Popup 矩形内外，不拦截或改写任何输入。

点标题栏 ×，或在窗口级 `PreviewKeyDown` 里按 Esc（先复位到图标页、再复用同一条关闭路径；弹出菜单打开时由菜单自行消费），都会触发 `MainWindow.OnClosing`：默认取消关闭并调用 `HideToTray()`（`Hide()` + 挂起空闲资源 + 托盘切到「后台运行」文案），进程不退出；只有注册表新键 `CloseEndsProcessV2 = 1`（设置页「关闭时结束进程」显式开启）才放行退出。旧键 `CloseEndsProcess` 已被忽略，避免升级用户继承 1.5 之前「点 × 即退出」的默认值。系统注销 / 关机由 `Application.SessionEnding` 放行，托盘右键「退出并结束进程」与设置页、更多菜单的退出按钮都走 `Quit()`。`Quit()` 是进程级硬退出：WPF 的 `Application.Shutdown()` 只结束 Dispatcher 循环，在托盘常驻 / 弹出菜单 / 消息钩子状态下可能留下「窗口已隐藏但进程还在」的僵尸实例（继续锁住 bin 目录里的程序集）。因此 `Quit()` 先收起菜单并卸载鼠标钩子、注销全局热键、停掉自动收纳计时器、释放托盘图标、注销 IPC 等待与互斥体并删除 `instance.pid`，再由 `AppExit.Exit()` 调用 `Environment.Exit(0)`；收纳状态每次操作都已 `WriteThrough + Flush` 同步落盘，无需额外存盘。关闭偏好为 1、安装器 `--maintenance=stop` 与单实例副本也复用同一条路径，副本实例直接硬退出，不会残留第二个进程。

图标解码管线不再常驻：`IconJobQueue` 最多拉起 2 条 STA 线程，仅在有解码任务时启动，空闲 20 秒后自行退出；`IconCache` 以 48 MB 位图字节为预算做 LRU 淘汰，跨屏 DPI、窗口缩放与图标库滚动产生的不同尺寸键不会无限累积。`ShellIntegration.IconReady` 仍按缓存键定向通知单个控件，避免广播风暴。

主窗口 `WindowState=Minimized`，或点 × 隐藏到托盘（`HideToTray()`，此时 `WindowState` 不变）时进入挂起态（`MainWindow.SuspendIdleResources`）：清空 `SkinBackdrop` 视觉层、释放壁纸 `BitmapSource` 与 `ImageBrush`、卸载「全部图标」页的上百个卡片控件（保留 `_catalogEntries` 纯数据与勾选集合）、把图标缓存收缩到预算的 35%，并让自动收纳降到 60 秒间隔。壁纸平均色调字符串特意保留，恢复显示时原生皮肤无需重新解码取色。启动即最小化（开机自启）时，`OnLoaded` 会显式同步一次挂起态，避免 `StateChanged` 未触发而漏掉释放。

恢复显示（`ResumeIdleResources`）由 `ShowPanel()` 统一触发（托盘隐藏态没有 `StateChanged`，必须显式调用），先同步重建背景层，再以后台优先级重建图标库卡片；挂起态下的 DWM 材质收敛、系统主题事件与 DPI 刷新路径都只更新声明、不重新加载壁纸位图。自检模式（`KeepOpenForVerification`）跳过挂起，保证原生界面自检观察到的视觉树不变。

自动收纳的每轮扫描用 `HashSet` 索引已收纳路径，把复杂度从 O(桌面条目 × 状态条目) 降到 O(桌面条目)；「快捷方式是否指向程序自身」的 COM 判定按路径与写入时间缓存（上限 256 条），目标未改写时不再创建 `WScript.Shell`。

## 在线更新

在线更新源为 `chenmo02/tomato-desktop`：客户端查询该仓库的最新正式版，仅接受该仓库的 `DesktopNook-Setup.exe`，无需发布凭据。发布记录须带 `digest`（`sha256:…`）与 `size`，与下载地址、文件来源一起校验，缺失即拒绝更新。`OnlineUpdater.Repository` 留空时 `Enabled=false`，可作为停用开关。

下载核对来源、大小、SHA-256、产品名和版本。确认后交给独立助手，等待当前程序正常退出，备份旧程序并替换，再启动新版并等待就绪确认。手动检查、确认、下载、校验与等待重启共用一个 480px 更新窗口（`UpdateWindow.cs`）；后台检查仍只提示、不弹窗，窗口状态与色板跟随主面板主题。

更新不迁移收纳内容，会保存元数据快照。替换失败时尝试还原；新版未确认就绪时保留备份和更新记录。

## 验证范围

覆盖故障恢复、同名保护、附加流、文件/目录往返、快捷方式启动、原生 OLE 拖入、跨进程 OLE 拖出格式、资源管理器展示目录同步、软件图标（含 Shell 实测图标留档）与命名空间 CLSID、次要按钮前景色（四套皮肤/主题色板）、窗口大小与置顶偏好、托盘图标与关闭行为（× 隐藏到托盘、旧偏好键不继承、托盘唤起与退出菜单）、托盘菜单的 WinUI 外观、无彩色底块、浅色 / 深色主题跟随、点击内 / 外的收起行为与鼠标钩子按需装卸、托盘退出项的进程级硬退出与资源清理（`AppExit` 注入替身，UI 自检不结束自身进程）、图标像素、后台资源上限和更新；另断言全局热键为 Ctrl + Alt + T（界面文案与实际注册组合一致）、Esc 关闭页面走与 × 相同的托盘路径。`scripts/Verify-StartupExit.ps1` 另在真实进程上覆盖：开机自启最小化、单实例副本立即退出、× 隐藏到托盘、托盘唤起、关闭偏好为 1 时终止进程、「更多 → 退出并结束进程」终止进程，以及 `--verify-tray-exit` 探针在隐藏态点击托盘右键退出项后进程确实结束、收纳数据不变。原生检查需要可交互 Windows 桌面；`--resource-self-test` 是纯内存自检，不读取或改动真实桌面，也不需要隔离目录。

混合 DPI 多屏的完整组合仍待实机覆盖。Shell 扩展、公共桌面权限和图标原资源质量受具体系统及应用影响。
