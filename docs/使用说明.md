# 使用说明

## 入口与分类

安装包会在桌面和开始菜单创建“番茄桌面”快捷方式。首次打开后，右键任务栏图标，选择“固定到任务栏”。点击入口打开面板，再次点击、按 Esc、按热键或点 × 可手动收起；点击面板外默认不会自动收起，需要该行为时到「设置 → 行为 → 失焦时自动收起」开启。若任务栏仍显示空白文档图标，用“更多 → 创建桌面与开始菜单入口”重建快捷方式后重新固定。

窗口按 Windows 11 / WinUI 3 设计稿 1:1 实现，默认 1040×680 逻辑像素，Viewbox 缩放恒为 1:1。48px 标题栏左侧是应用自己的番茄图标与“番茄桌面”名称，右侧是三个 46×48 标准 caption 按钮（最小化、窗口大小菜单、关闭；关闭悬停为系统红）。左侧 236px NavigationView：顶部“查找分类”输入框按名称过滤分类行，“全部”始终保留；分「桌面」与「分类」两组纯文字标题，分类行高 36px、右侧显示该分类的项目数，选中用中性浅灰底加 3px 灰色指示条（不使用蓝色框或蓝色选中块），行首不显示图标。底部是固定“设置”入口与版本文字。新建分类在“更多 → 新建分类”或分类行右键菜单里；右键分类行可重命名、向前/向后移动或删除；按住分类行直接拖动即可自定义排序（往下拖排到目标之后、往上拖排到目标之前，「未分类」固定末尾），顺序写入数据文件并支持 Ctrl+Z 撤销。窗口默认打开第一个自定义分类而非「全部」，无自定义分类时回退到「全部」；手动切回「全部」后不会被重新选中。上下方向键（兼容左右键）在分类间循环，Home/End 跳到首尾。

右侧内容区顶部是 28px Light 大标题与 12px 副标题，CommandBar 与大标题同一行右对齐，依次为“搜索图标”输入框、撤销（Ctrl+Z）、全部图标、＋喂给番茄、更多（无排序按钮，图标顺序靠拖动或右键“前移/后移”调整）；再往下是单行完整文案、可关闭的 InfoBar 提示条、“已固定”分区标题与计数徽标，以及八列开始菜单式图标网格（44px 真实应用图标居中在上、名称居中在下最多两行，默认无卡片底色与描边，图标右侧不留空白；分类信息保留在鼠标悬停提示里）。图标可拖动调整顺序，松手后自动吸附回整齐网格。「已固定」标题行右侧提供「全部移除」按钮：点一下并确认即可把当前显示的项目全部移回桌面，可先用分类或搜索筛选只移除一批；桌面已有同名文件时自动改名，结果可按 Ctrl+Z 逐项撤销，失败项会单独列出。CommandBar 的“▦”或“更多 → 浏览全部图标…”打开全部图标页面（覆盖右侧内容区），可从开始菜单与系统应用里挑图标（页面按「分组标题 + 计数徽标 + 横向分隔线」分区，7 列透明磁贴默认无底色、名称两行居中，悬停或选中才浮出底色与右上角状态标记，底部操作栏用分隔线与内容区隔开）；默认隐藏 Windows 工具、命令行、诊断组件以及卸载程序/帮助/文档/官网等非应用入口，需要时到「设置 → 行为 → 显示系统项目」开启（偏好会保存并随配置包导出/导入）；应用列表在后台读取、图标按滚动到的位置按需加载，打开页面不会阻塞窗口；“更多 → 文件管理”子菜单提供资源管理器与常用位置。“更多”菜单还提供自启、关闭行为、窗口大小、本地文件更新和数据目录入口。“−”只最小化；“▢”打开窗口大小菜单；“×”按关闭偏好执行；“退出并结束进程”始终退出。

全局字体使用系统自带字体栈 Segoe UI Variable Text → Segoe UI → Microsoft YaHei UI → Microsoft YaHei，不再使用符号字体；放大镜、四宫格、加号、更多与窗口按钮全部改为 1.4px 线性图标。图标磁贴对齐 Windows 11 开始菜单「已固定」：原生与玻璃两套皮肤下都完全透明、无描边、无右上更多符号，图标与名称直接落在窗口底上，不会各自套一张白色卡片；悬停或键盘聚焦只浮出一层极淡的 8px 圆角底色。侧边栏底色比内容区略灰，不设底部状态栏，内容区直接延伸到窗口底边；原先在状态栏显示的轻提示不再可见，重要结果仍通过弹窗、InfoBar 与操作日志呈现。窗口圆角 12px、磁贴 8px、控件 6px；所有输入框（侧栏与内容区检索框、全部图标页检索框、新建/重命名弹窗）统一为白底、1px 中性描边、6px 圆角并带占位文字，聚焦时描边保持中性灰，底部沿圆角轮廓浮出 1.6px 聚焦底线（140ms 淡入、120ms 淡出，两端自然收进圆角而非直角蓝条）；底线在原生皮肤跟随系统强调蓝、玻璃皮肤改用中性灰蓝，避免固定番茄红被误读成校验失败。检索框的占位文字与输入光标共用同一内边距，聚焦时光标停在提示文字之前而非插进文字中间。界面不出现蓝色方框或蓝色选中块。弹窗输入框另有字符计数，空值时「保存」直接禁用；取消与保存分别使用中性次要按钮和蓝色主操作按钮。配色为中性白灰与系统强调蓝 #0067C0，强调色只用于主操作按钮、InfoBar 与文字链接。“更多”菜单与所有右键菜单均为纯文字项，不显示行首图标。全站滚动条统一为 4px 细条，默认 25% 不透明度、鼠标移到滑块上才加深到 85%，避免粗灰条压在内容右侧。

程序默认跟随 Windows 应用的深浅主题与系统强调色，也可在「设置 → 外观」里固定为浅色或深色、或改用默认蓝。色板通过动态资源整体替换，主窗口、弹窗、菜单与设置页同步变色；深色态为窗口 #202020、侧栏 #1B1B1B、面板 #2B2B2B、强调 #4CC2FF。

**皮肤**：「设置 → 外观 → 皮肤」可在「原生系统」（默认）与「玻璃拟态」之间切换，选择立即生效并写入偏好，配置包导出/导入会一并带上。玻璃拟态使用半透明色板、4px 小圆角窗口、淡化细描边、柔和外光晕与 16px 提示条，图标磁贴仍保持无底色，主操作改为番茄红；强调色固定为番茄红，因此「强调色跟随系统」在该皮肤下置灰。深浅主题对玻璃皮肤同样生效：浅色为白玻璃配深色文字，深色为蓝紫玻璃配浅色文字。切回「原生系统」时，圆角、色板、磁贴透明底与壁纸取色全部复位，原外观 1:1 不受影响。

背景采用静态 Mica：面板只铺一层 Alpha 完全不透明的浅色底，挡住背后应用窗口的实时透视；当前桌面壁纸只用于取平均色调，以 10% 权重混入底色并钳制亮度，不显示壁纸图案，也不会出现网页、文档文字的残影。壁纸更换时自动刷新；纯色壁纸或读取受限时回退为中性浅灰，文字对比度保持不变。系统级 Mica 需要非 layered 窗口，会牵动圆角、贴任务栏与拖动逻辑，因此未采用；取色放在窗口显示后的后台优先级，不占用首次启动路径。

玻璃拟态皮肤使用 Windows 11 系统 Acrylic 背板：程序窗口从分层窗口（`AllowsTransparency=True`）改为非 layered 窗口 + `WindowChrome` 完整玻璃帧，WPF 合成目标背景色设为透明，由 DWM 实时把窗口背后的桌面与其它窗口模糊后透出；原有的自定义拖动、自由缩放与贴任务栏逻辑不变。原生皮肤使用系统 Mica，仍铺不透明底。系统要求 Windows 11 22621+ 且开启桌面合成、未启用高对比度。

DWM 背板按整个窗口矩形合成，若 HWND 仍是直角，WPF 圆角外的四角会露出没有玻璃覆盖的纯背板色，形成四个淡蓝直角方块。因此 `BackdropService` 另用 `SetWindowRgn` 把窗口区域裁成与内容一致的圆角；半径按 `GetWindowRect` 的真实物理矩形与 Viewbox 缩放换算，窗口尺寸、DPI、皮肤或深浅主题变化时重裁。玻璃皮肤最终取 4px、原生保留 12px：region 裁剪后四角会直接露出桌面，22px 大圆角会把高饱和壁纸「挖」进窗口形成生硬缺口，同时亮白描边弧线显得突兀，因此圆角逐级收小到 4px 并把 `WinStroke` / `WinStrokeSoft` 降到 50% / 30% alpha。region 同时裁剪鼠标命中区域，所以四角缩放把手由 8px 向内扩展到 26px，保证圆角内仍有可拖动热区。region 尺寸若按 `ActualWidth × DPI` 估算会偏小、连图标区一起裁掉，导致拖放收纳失效，因此必须以真实窗口矩形为准。

Acrylic 生效时，玻璃背景层的根节点保持完全透明、不铺任何不透明渐变；窗口底、backplate 与内容区共用的半透明白画刷 alpha 压到 8%–12%，光斑强度降到 30%。这几层若按常规透明度叠加，会把 DWM 背板糊成一块浅色纯色面板——这是「开启了透明效果却看不到透视」的典型原因。只有回退态才铺不透明渐变并启用壁纸裁切层。

**系统「透明效果」是前提**：若「设置 → 个性化 → 颜色 → 透明效果」关闭，Acrylic 会退化为纯色，程序会自动回退到按窗口屏幕位置裁切并模糊的壁纸层（玻璃观感保留，但不实时透视背后窗口）；开启该开关后无需重启即自动切回真·Acrylic。旧系统、高对比度或 DWM 调用失败时同样回退。皮肤下拉按钮的提示文字显示当前背板状态。输入框、卡片、菜单和弹窗始终使用高不透明度底色，正文对比度不变。回退层的壁纸裁切按主屏尺寸与「填充 / 拉伸」两种样式计算，跨屏与混合 DPI 场景按主屏近似。

## 设置、撤销与数据

侧栏底部「设置」或「更多 → 打开设置」进入独立设置页，分外观、行为、数据与备份、关于四组：

- 外观：皮肤（原生系统 / 玻璃拟态）、主题（跟随系统 / 浅色 / 深色）、强调色跟随系统（玻璃拟态下置灰）、顶部提示条开关（关闭后不再出现）。
- 行为：开机自启、全局热键 Ctrl+Alt+T、**失焦时自动收起（默认关闭）**、自动收纳新桌面图标（默认关闭，每 15 秒扫描，可立即扫描）、**显示系统项目（默认关闭，作用于「全部图标」页）**、关闭时结束进程。默认关闭自动收起后，点击桌面或其它应用窗口面板也不会消失，必须手动点 ×、按热键或点任务栏按钮收起；需要恢复「点外部即收起」时再打开该开关。偏好写入 `AppSettings`，随配置包导入导出。
- 数据与备份：导出/导入配置包（zip，含分类、图标、托管副本与偏好；导入前自动备份，路径会重映射到本机桌面）、查看最近操作日志、打开数据目录、检查并清理失效入口。
- 关于：版本与本地运行说明、创建桌面与开始菜单入口、退出并结束进程。

设置页按 Windows 11 设置应用排版：分组标题在卡片外，卡片为 8px 圆角白底 + 1px 中性描边；内部每行统一 64px 高、左右 20px 内边距，行与行之间用左右内缩的 1px 细分隔线，悬停浮出极淡底色。行标题 14px SemiBold、说明 12px 次要色；开关使用 40×20 ToggleSwitch（160ms 平移），主题用带下拉箭头的选择器，其余操作统一为次要按钮。切到设置页时侧栏「设置」行同步显示选中态。

所有数据只保存在本机数据目录，不上传、不联网；在线更新当前停用。原先藏在「更多」菜单里的自启与关闭行为已迁到设置页。

**撤销**：收纳、移回桌面、分类新建/重命名/删除/排序、图标改名/移动/排序/归档等改动都进入最近 20 步撤销栈，按 Ctrl+Z 或点 CommandBar 的撤销按钮即可回滚；操作结果不再有底部文字提示，失败项不会静默跳过。操作日志保留 30 天，可在设置里查看。

**快速启动**：任意界面按 Ctrl+Alt+T 唤起或收起面板；在「搜索图标」框输入名称后按回车直接打开第一个匹配项。热键被其它程序占用时可在设置里关闭。

**收纳预览与失效检测**：拖入文件前会计算待收纳数量、已收纳跳过项与失效快捷方式数；启动时后台校验快捷方式目标，失效图标整体标灰并提示，可在设置里批量移除（可按 Ctrl+Z 撤销）。

**自动收纳**：开启后桌面新增的可见项目会自动收进「未分类」，跳过隐藏项、程序自身、临时文件与正在写入的文件；默认关闭，避免误收。

## 收纳与移回

- 拖入桌面项目，或通过“喂给番茄”多选，再指定分类。
- 图标始终按开始菜单式紧凑网格排列（图标在上、名称在下居中）；拖动图标可调整顺序，松手后自动吸附回网格，不会散落。搜索状态下需先清空关键词才能调整顺序。
- 把图标拖到左侧边栏的分类行可直接归类；收纳时默认归入当前选中的分类；在「全部」视图下归入「未分类」。
- 单击图标打开；通过右键“移回桌面”或把图标拖出面板放到桌面上恢复。
- 同名目标不覆盖，可选择改名恢复。“全部移回桌面”中的失败项继续保留，供重试。
- 来自「所有用户」公共桌面（`C:\Users\Public\Desktop`）的快捷方式，系统通常只允许读取、不允许写回。移回时程序会自动把它放回当前用户桌面并自动处理，不会弹出权限错误；自动收纳也不会搬动公共桌面项目。
- 收纳时若没有权限删除原快捷方式，程序会完整回滚本次收纳（状态、托管副本、迁移日志一并撤销），原文件与原有数据都不受影响。

普通文件和文件夹是移动实际内容。软件快捷方式只移动对应入口，不搬动安装本体。回收站使用系统入口和桌面可见性设置，移回时还原原设置，不清空内容。

## 窗口大小

“更多 → 窗口大小”提供 80%、100%、125%、150%。100% 为默认 1040×680 逻辑像素（与设计稿 1:1）。标题栏「▢」与「更多」里的窗口大小共用同一套菜单项；弹出前会先从临时父菜单断开逻辑父级，避免复用菜单项时报「元素已具有逻辑父级」。

“自由调整”允许拖动四边和四角；“锁定宽高比”保持窗口 8:7 形状。尺寸自动保存，可用“恢复默认大小”复位。

按住顶部标题栏（图标、文字或空白处）可把面板拖到任意位置，位置会自动保存，重新打开仍停留在该处；按钮上按下不会触发拖动。想恢复贴着任务栏显示，用“更多 → 窗口大小 → 贴回任务栏”。

**所有模式均保持图标和名称大小不变。** 右侧内容区宽度决定列数（默认尺寸为八列，磁贴约 93px 一格，加宽窗口自动增列、收窄自动减列），高度决定可见行数，超出时纵向滚动。图标继续随屏幕 DPI 请求适当的物理像素。

## 更新

**在线更新源当前停用**：启动后不会访问 GitHub，也不会提示“发现新版本”；“更多”菜单里的“在线更新未启用（当前 v版本号）”为灰色不可用。等确定新的发布仓库地址并配置后，会自动恢复启动后台检查与手动检查（后台检查只提示、不自动安装）。

当前请用本地文件更新：

1. 从 Releases 下载新版 `DesktopNook-Setup.exe` 或 `DesktopNook-win-x64.exe`。
2. 点击“更多 → 从本地文件更新…”，选择下载好的程序或安装包。
3. 版本、产品标识与文件校验通过后，自动在原位置更新并重启。

安装版也支持直接覆盖升级，通常无需先卸载。免安装版应保持 EXE 的文件名和位置，以维持任务栏与自启入口有效。

## 数据与卸载

“更多 → 打开数据目录”可查看记录，默认路径为 `%LOCALAPPDATA%\DesktopNook`。完整备份需要包含实际托管内容及可能位于原桌面同卷的 `.DesktopNookVault`，见[架构与数据](架构与数据.md)。不要直接删除这些目录。

卸载先尝试恢复已收纳项目。仍有恢复失败的项目时停止卸载并保留程序，请处理冲突或占用后重试。

反馈问题时提供软件版本、Windows 版本、屏幕缩放比例和复现步骤即可；不要公开上传整个数据目录或含个人路径的原始状态文件。
