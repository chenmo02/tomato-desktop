# 番茄桌面 <small>DesktopNook</small>

<img src="native/DesktopNook.App/Assets/AppIcon.png" width="108" align="right" alt="番茄桌面图标">

**只收纳你选中的桌面图标，其余照旧留在桌面。** 番茄桌面是一个运行于 Windows 的桌面收纳工具：把快捷方式、文件或文件夹「喂给番茄」，之后从任务栏上的同一个入口按分类打开；需要时，一键把项目移回桌面。

## 为什么用它

桌面图标越堆越多，但全盘整理又容易把常用的东西弄丢。番茄桌面只搬运你明确选中的项目：

1. **收纳** — 拖入桌面项目，或点「＋ 喂给番茄」多选，指定分类。
2. **访问** — 点击任务栏入口打开面板，按分类或搜索找到项目，单击即可启动。
3. **还原** — 右键「移回桌面」、把图标拖出面板，或用「全部移除」批量恢复；出错还能按 `Ctrl+Z` 撤销。

快捷方式只移动对应的 `.lnk` / `.url` 入口，软件本体保持原位；普通文件和文件夹会连同内容一起托管，收纳期间的修改随移回操作保留。

## 主要功能

- **收纳与分类**：拖入 / 多选收纳、自定义分类（新建、重命名、拖动排序）、名称搜索、「全部移除」批量移回；同名目标自动改名，不覆盖。
- **跨程序拖出**：把图标拖出面板到浏览器、微信、资源管理器等外部程序，会切换为 Windows 标准拖放（FileDrop / FileNameW / 文本），网址快捷方式额外提供 URL 格式；拖到桌面仍是「移回桌面」，托管文件只允许复制、不会被搬走。
- **资源管理器入口**：安装版在文件资源管理器左侧导航窗格注册独立的「番茄桌面」入口（与「此电脑」同级，Windows 11 22H2+ 已限制「固定到快速访问」的编程接口），使用软件自己的图标，点开即可看到全部收纳项的快捷方式并直接打开；收纳、移回、改名、分类变化自动同步，卸载时自动清理注册。
- **快速启动与系统菜单**：开始菜单式图标网格，单击启动，右键整理、移回桌面或调用 Windows Shell 命令；支持收纳和移回系统回收站图标。
- **窗口与布局**：标题栏「▢」一键最大化 / 还原；「设置 → 窗口调整」提供 80% / 100% / 125% / 150% 预设比例、自由拖动边框、锁定宽高比、尺寸与位置记忆、随时贴回任务栏，以及「窗口置顶」开关（默认开启，偏好随配置包导入导出）；缩放窗口时图标与名称尺寸保持不变，只调整每行数量。
- **外观**：Windows 11 风格面板，跟随系统深浅主题与强调色，也可固定；「原生系统」（Mica）与「玻璃拟态」（Acrylic）两套皮肤即时切换。主界面图标按 2× 物理像素超采样后高质量缩小，避免圆边与渐变处的锯齿杂边；解码时归一化图标透明边缘的 alpha 数据，消除圆形图标外沿的白色光晕；偏好随配置包导入导出。
- **可撤销与可恢复**：收纳、移回、分类与排序改动进入最近 20 步撤销栈，操作日志保留 30 天；启动时校验失效快捷方式，可在设置里批量清理。
- **自动化与偏好**：全局热键 `Ctrl+Alt+T`、可选开机自启、自动收纳新桌面图标（面板可见时每 15 秒扫描、收起后降频到 60 秒并在恢复显示时立即补扫，默认关闭）、失焦自动收起（默认关闭）。
- **托盘后台驻留**：点标题栏 × 只隐藏窗口、不结束进程，通知区托盘图标常驻；左键 / 双击图标、点击任务栏入口或按热键都能重新打开，右键托盘图标打开与主界面一致的 WinUI 圆角菜单（品牌头、线性图标、快捷键提示，自动跟随浅色 / 深色主题；番茄图标不带彩色底块），可打开面板、打开设置或退出，点击菜单外任意位置即收起。真退出请用托盘右键菜单、「设置 → 关于 → 退出并结束进程」或「更多 → 退出并结束进程」：会先释放托盘图标、全局热键、鼠标钩子与单实例资源，再直接结束进程，任务管理器里不会残留无窗口的后台实例，也不会继续占用程序集文件。确需「点 × 直接退出」可在「设置 → 行为」显式开启（默认关闭）。
- **后台资源控制**：图标解码线程按需启动、空闲 20 秒自动退出；图标位图按 48 MB 预算做 LRU 淘汰；面板最小化或隐藏到托盘时释放玻璃壁纸位图、模糊背景层与「全部图标」页视觉树，恢复显示时按需重建，收纳数据、分类与设置不受影响。
- **统一更新窗口**：本地文件更新与在线更新共用一个 480px 窗口，按状态展示版本迁移、下载进度阶段、数据安全声明与失败重试；校验版本、产品标识与文件后在原位置替换并重启，保留分类、收纳内容和设置。

完整交互说明见 [使用说明](docs/使用说明.md)。

## 快速开始

### 1. 获取程序

支持 **Windows 10 / 11 x64**。安装包内含自带 .NET 桌面运行时的单文件程序，普通用户无需安装 .NET SDK。

| 文件 | 用途 |
| --- | --- |
| `DesktopNook-Setup.exe` | 安装版；首次安装或覆盖升级，会创建桌面与开始菜单快捷方式 |
| `SHA256SUMS.txt` | 发行文件的 SHA-256 校验值 |

请从本仓库的 [Releases](https://github.com/chenmo02/tomato-desktop/releases) 下载，附件以页面实际内容为准。若 Releases 暂时没有附件，可按下方「从源码构建」自行生成单文件程序。**Code → Download ZIP 得到的是源码，需要自行构建，不能直接运行。**

### 2. 首次使用

1. 运行安装版；
2. 右键任务栏上的「番茄桌面」图标，选择「固定到任务栏」；
3. 点击该入口打开或收起面板，把要整理的项目拖进来。

> 面板默认**不会**因点击桌面或其它窗口而收起，需点 ×、按热键或再点任务栏按钮；如需「点外部即收起」，到「设置 → 行为 → 失焦时自动收起」开启。

### 3. 常用操作

| 操作 | 方式 |
| --- | --- |
| 唤起 / 收起面板 | `Ctrl+Alt+T` |
| 撤销上一步 | `Ctrl+Z` |
| 收纳项目 | 拖入项目，或「＋ 喂给番茄」多选 |
| 归类 | 把图标拖到左侧分类行 |
| 移回桌面 | 右键「移回桌面」或拖出面板；「全部移除」批量恢复 |
| 打开搜索结果 | 在「搜索图标」框输入名称后按回车 |
| 在资源管理器访问收纳内容 | 左侧「快速访问 → 番茄桌面」 |
| 外观 / 窗口调整 / 行为 / 备份 | 侧栏底部「设置」或「更多 → 打开设置」 |

## 从源码构建

需要 Windows、**.NET 10 SDK** 和 **PowerShell 7**；构建安装包另需 Unicode NSIS，发布到 GitHub 另需已登录的 GitHub CLI。

```powershell
git clone https://github.com/chenmo02/tomato-desktop.git
cd tomato-desktop
pwsh -NoProfile -File native/scripts/Build.ps1
```

产物为含运行时的 x64 单文件程序 `native/artifacts/win-x64/DesktopNook.exe`。脚本会先生成多尺寸图标并运行核心检查；只需重复打包时可加 `-SkipTests`。

只编译开发版本：

```powershell
dotnet build native/DesktopNook.App -c Release
```

**调试请务必使用隔离目录**，正常运行会操作真实桌面与当前用户数据：

```powershell
$profile = Join-Path $env:TEMP ('DesktopNook-dev-' + [guid]::NewGuid().ToString('N'))
dotnet run --project native/DesktopNook.App -c Release -- --sandbox $profile
```

核心检查与安装包：

```powershell
dotnet run --project native/DesktopNook.Tests -c Release -- native/test-results/core.json
makensis /V2 native/scripts/Installer.nsi   # 需要 Unicode NSIS，输出 native/artifacts/DesktopNook-Setup.exe
```

完整的测试、安装器与发行步骤见 [开发与构建](docs/开发与构建.md)；从版本号 bump 到发布 Release 的可执行清单见 [打包与发布](docs/打包与发布.md)。原生 UI 自检会短暂操控鼠标，必须在专用隔离目录中运行。`native/scripts/Verify-StartupExit.ps1` 在真实进程上核对启动、单实例、后台驻留与所有真退出入口结束后无残留实例（脚本需 UTF-8 BOM + CRLF，供 Windows PowerShell 5.1 正确读取中文注释）。

## 数据与备份

> **重要**：收纳会移动真实桌面文件。请通过「移回桌面」或卸载恢复流程取回内容，不要直接删除数据目录、托管目录或跨卷托管内容。

- 分类、收纳索引与恢复清单默认保存在 `%LOCALAPPDATA%\DesktopNook`（`state.json`、`migration.json`、`vault/`、`updates/`）；程序本体 `DesktopNook.exe` 与卸载器也安装在该目录，覆盖升级只替换程序文件，不改动数据。
- 跨卷托管的文件可能位于原桌面同卷的隐藏 `.DesktopNookVault`，只备份 JSON 或默认数据目录不足以覆盖全部实际内容。
- 窗口、主题、自启、置顶与关闭行为等偏好保存在当前 Windows 用户设置；「设置 → 数据与备份」可导出 / 导入 zip 配置包，导入前会自动备份。1.5 起「关闭时结束进程」改由新键保存并默认关闭，旧版本写入的旧值不再被继承，避免点 × 意外退出。
- 所有数据仅保存在本机，不上传、无云端或跨设备同步；卸载时会先尝试恢复已收纳项目，有失败项时保留程序以便重试，恢复成功后数据目录仍保留，需手动清理。

细节见 [架构与数据](docs/架构与数据.md)。

## 项目状态与已知限制

- 当前源码版本 **1.5.1**，基于 WPF / .NET 10（`net10.0-windows`），面向 Windows 10 / 11 x64。
- **在线更新已启用**：`OnlineUpdater.Repository` 指向 `chenmo02/tomato-desktop`，启动后台检查与「更多 → 检查在线更新」均可用；检查与下载需能访问 GitHub。发布资产必须为 `DesktopNook-Setup.exe`，且 GitHub 返回的 `digest`（`sha256:…`）与 `size` 有效，下载地址须落在该仓库的 `/releases/download/` 路径下，否则检查会拒绝更新而不下载。
- 公共桌面快捷方式与被占用文件受 Windows 权限限制，失败时保留原项目并提示；符号链接、目录联接及未落地的云占位内容暂不按普通文件夹收纳。
- 图标清晰度受原应用资源限制；跨屏 DPI 切换已由 `--dpi-self-test` 覆盖（窗口圆角区域、内容层与壁纸对齐会随 DPI 重算），但不同显示器缩放组合仍未逐一实机验收。
- 玻璃拟态皮肤依赖 Windows 11 22621+ 且系统「透明效果」开启，不满足时自动回退到按窗口位置对齐的模糊壁纸层；壁纸对齐按整个虚拟屏幕的物理像素计算，扩展屏摆在左侧（负坐标）时同样有效。
- 后台资源自检（`--resource-self-test`）验证缓存上限、线程空闲退出与自动收纳降频；面板收起后的实际工作集仍随壁纸尺寸、图标数量与 Windows 缓存策略变化，不承诺固定数值。
