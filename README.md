# 番茄桌面

一个运行于 Windows 的桌面收纳工具：把自己选择的桌面快捷方式、文件或文件夹喂给番茄，再通过任务栏上的一个入口按分类访问。没有选择收纳的项目继续留在桌面。

**当前源码版本：1.2。** 本仓库保存原生 Windows 源码、开发文档及正式发行包。程序内的在线更新源当前停用（未配置发布仓库），启动后不会检查 GitHub 新版本；待指定新的仓库地址后填入 `native/DesktopNook.App/OnlineUpdater.cs` 的 `Repository` 即可恢复。

## 下载与运行

支持 Windows 10/11 x64。发行包包含 .NET 桌面运行时，普通用户无需安装 .NET SDK。

| 下载文件 | 用途 |
| --- | --- |
| `DesktopNook-Setup.exe` | 安装版；首次安装或覆盖升级 |
| `DesktopNook-win-x64.exe` | 免安装版；建议放在固定目录后运行 |
| `SHA256SUMS.txt` | 发行文件的 SHA-256 校验值 |

请从 **Releases** 下载安装包。**Code → Download ZIP** 下载的是源码，需要自行构建。

安装版会在桌面和开始菜单创建“番茄桌面”快捷方式。首次打开后，右键任务栏上的“番茄桌面”图标，选择“固定到任务栏”。点击同一个任务栏入口可打开或收起面板。

## 已实现功能

- **手动选择收纳**：拖入桌面项目，或点击“喂给番茄”多选。成功后原桌面入口移入托管区；移回桌面可恢复。
- **全部移除**：「已固定」标题行右侧一个按钮即可把当前显示的图标全部移回桌面，可先用分类或搜索筛选只移除一批；桌面同名文件自动改名，每项都能按 Ctrl+Z 撤销。
- **分类管理**：新建、重命名、删除分类，通过顶部标签筛选；“全部”显示所有收纳项。
- **快捷启动与系统菜单**：单击启动，右键整理、移回桌面或访问 Windows Shell 命令。
- **文件和文件夹**：托管实际内容，收纳期间的修改会随移回操作保留。
- **回收站入口**：支持收纳和移回系统回收站图标，不清空回收站内容。
- **窗口大小与位置**：80%、100%、125%、150% 固定比例；自由拖动边框、锁定宽高比、尺寸记忆；按住标题栏可拖动面板并记住位置，可随时贴回任务栏。
- **固定图标大小**：所有窗口比例下，图标和名称保持默认尺寸；窗口宽度改变每行图标数量，图标取图适配屏幕 DPI。
- **皮肤切换**：「设置 → 外观 → 皮肤」可在原生系统（系统 Mica）与玻璃拟态（Windows 11 系统 Acrylic 实时背板、半透明面板、亮描边与柔和光晕）之间即时切换；原皮肤保留，偏好随配置包导入导出。Acrylic 需 Windows 11 22621+ 且系统「透明效果」开启，不满足时自动回退到按窗口位置对齐的模糊壁纸层。窗口 HWND 也按皮肤圆角（玻璃 4px / 原生 12px）裁剪，避免 DWM 背板在四角留下直角色块；玻璃皮肤采用小圆角配合淡化描边，四角不会把桌面壁纸「挖」成大缺口，四角缩放把手相应向内扩展以保持可拖动。图标磁贴在两套皮肤下均无底色，悬停只叠一层极淡反馈；输入框聚焦底线在玻璃皮肤改用中性灰蓝，避免番茄红被当成校验错误，占位文字与输入光标也统一了内边距。面板默认**不自动收起**：点击桌面或其它窗口后面板保持显示，只能通过 × / 热键 / 任务栏按钮手动收起；「设置 → 行为 → 失焦时自动收起」可按需重新开启。
- **启动与关闭偏好**：可选开机自启，以及关闭按钮退出或仅收起到任务栏。
- **更新**：支持“更多 → 从本地文件更新…”，选择新版 EXE 或安装包完成校验、替换与重启；在线更新源当前停用，启动后不做后台检查，配置发布仓库后可恢复。

## 收纳数据与更新

快捷方式收纳会移动对应 `.lnk` / `.url` 文件，软件安装本体保持原位。普通文件和文件夹收纳则会移动实际内容。请通过“移回桌面”或卸载恢复流程取回内容，不要直接删除数据目录、托管目录或跨卷托管内容。

分类、收纳记录与恢复信息默认保存在 `%LOCALAPPDATA%\DesktopNook`。窗口、自启和关闭偏好由当前 Windows 用户的设置保存。完整备份还需要包含实际托管内容，见[架构与数据](docs/架构与数据.md)。

更新保留分类、收纳内容和设置，通常不需要先卸载。在线更新当前停用，请手动下载新版后使用“从本地文件更新”；恢复在线更新后，下载需要能访问 GitHub 并使用系统网络/代理设置，失败时可继续使用当前版本。

## 从源码构建

需要 Windows、**.NET 10 SDK** 和 PowerShell 7。构建安装包另需 Unicode NSIS；发布到 GitHub 另需已登录的 GitHub CLI。

```powershell
git clone https://github.com/fangmingzhao69-glitch/desktop-nook-releases.git
cd desktop-nook-releases
pwsh -NoProfile -File native/scripts/Build.ps1
```

脚本生成 ICO、运行核心检查，并输出包含运行时的单文件程序：`native/artifacts/win-x64/DesktopNook.exe`。

只编译开发版本可运行：

```powershell
dotnet build native/DesktopNook.App -c Release
```

完整测试、安装器和发行步骤见[开发与构建](docs/开发与构建.md)。原生 UI 检查会短暂操控鼠标，必须使用专用隔离目录。

## 当前限制与项目状态

- 本地优先，无云端同步或跨设备数据同步。
- 公共桌面或被占用文件受 Windows 权限限制，失败时保留原项目并提示。
- 符号链接、目录联接及未落地的云占位内容暂不作为普通文件夹收纳。
- 图标清晰度受原应用资源限制；已覆盖尺寸/DPI 计算与当前屏幕验证，混合 DPI 多屏的完整组合尚未实机验收。
- 在线更新当前停用；恢复后公开更新查询无需登录，程序不包含发布账号令牌。GitHub 下载速度受网络影响。
- 当前提交对应 1.2 实现。此前发行标签早于源码首次提交，源码请使用本仓库主分支或额外提供的源码压缩包；旧标签自动生成的 Source code 压缩包不代表当前源码。

仓库只提交源码、必要的应用图标和文档；构建结果、测试报告、本机分类、文件及恢复备份不纳入 Git。
